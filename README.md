# Wireshark Network Traffic Analysis

## Objective
Analyze different types of network traffic using Wireshark packet analyzer.

## Tools Used
- Wireshark
- Windows 11

## Protocols Analyzed
- HTTP
- DNS
- TCP Three-Way Handshake
- TCP Analysis Flags

## Work Performed
- Captured live network packets
- Filtered HTTP traffic
- Filtered DNS queries and responses
- Observed TCP SYN and SYN-ACK packets
- Analyzed retransmissions and duplicate ACK packets
